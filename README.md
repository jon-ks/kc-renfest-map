# KC Ren Fest Map

Interactive map of the Kansas City Renaissance Festival grounds. Tap or hover any booth, food stall, stage, game or landmark to see its name and category. Includes search, category filters, a starred "our list", directions, and ticket links.

Static site: `index.html`, `map.jpg`, `og.jpg`. No build step.

## Deploy on Vercel
Import the repo, Framework Preset: **Other**, leave build and output settings empty.

The share preview (`og:image`, `og:url`) points to `https://kc-renfest-map.vercel.app`. If Vercel assigns a different domain, update those two meta tags in `index.html`.

Source data: KCRF 2024 festival map and program.
